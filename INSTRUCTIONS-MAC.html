Set up the Pickleball Booker on a Mac

This app books a 2-hour court for you at Club Pickle & Padel on Plan2Play. It tries at midnight, the moment a date opens 10 days ahead. Follow the steps in order. Setup takes about 20 minutes, and nothing gets booked until step 9. On a Windows PC, use INSTRUCTIONS.html instead.

Before you start

  • A Mac (laptop or desktop) that can stay on and plugged in overnight on booking nights, with the lid open.
  • The file PB-Registration-HP.zip that was sent to you.
  • Your own Plan2Play login. Bookings go on your account.
  • Optional: a Gmail address, if you want results by email.

The steps at a glance

  1. Unzip and move the folder
  2. Run setup
  3. Add your Plan2Play login
  4. Set up email (optional)
  5. Choose days, times and courts
  6. Keep your Mac awake overnight
  7. Run a test
  8. Check the nightly job
  9. Turn on real booking
1

Unzip and move the folder

  1. Double-click PB-Registration-HP.zip in your Downloads. A PB-Registration-HP folder appears next to it.
  2. In Finder, click the Go menu, then Home. This is the folder with your name and a house icon.
  3. Drag the PB-Registration-HP folder into your Home folder.

Don't keep it in Documents, Desktop, Downloads or iCloud Drive. macOS stops nightly jobs from reading those folders, so the booker would quietly fail at midnight. Setup checks this and tells you if the folder is in the wrong place.

If you move the folder later, run step 2 again.

2

Run setup

The first time, start setup from Terminal. macOS blocks downloaded scripts from opening with a double-click until setup has run once.

  1. Open Terminal: press Command + Space, type Terminal, and press Return.
  2. Type bash followed by a space. Don't press Return yet.
  3. Drag setup.command from the PB-Registration-HP folder into the Terminal window. Its location fills in. Now press Return.
  4. If you don't have Node.js, the software the app runs on, setup downloads its installer and opens it. Click through the installer (it asks for your Mac password), then do steps 2 and 3 above again.
  5. Setup asks whether this Mac should wake itself at 11:40 PM every night. Type y and press Return, then type your Mac password (nothing shows as you type) and press Return. Type n to skip it.
  6. Wait until the window says Setup is done.

Setup also creates the nightly job and opens a TextEdit window for the next step. After this, every .command file in the folder opens with a double-click.

3

Add your Plan2Play login

In the TextEdit window, type your Club Pickle & Padel login id and password straight after each = sign, with no spaces or quotes. Here is the login if you need to reset your password: https://work1.plan2play.com/login

PLAN2PLAY_USERNAME=you@example.com
PLAN2PLAY_PASSWORD=your-password

Leave ALLOW_REAL_BOOKING=false as it is for now. Save with Command + S, but keep TextEdit open if you're doing step 4.

  • One exception: if your password contains a #, put it in double quotes, like PLAN2PLAY_PASSWORD="abc#123". Otherwise the app only reads the part before the #.
  • If TextEdit turns your quotes into curly ones, go to the Edit menu, then Substitutions, and untick Smart Quotes. Then type them again.
  • This file stays on your Mac. Don't send it to anyone, because it holds your password.
  • The file is called .env, and Finder hides names that start with a dot. To open it again later, open Terminal and type open -e ~/PB-Registration-HP/.env, then press Return. Or press Command + Shift + . in Finder to show hidden files.
4

Set up email (optional)

Mac notifications work without this. Add email if you want results sent to your inbox too.

  1. Sign in to your Gmail and go to myaccount.google.com/apppasswords. If the page isn't available, turn on 2-Step Verification first.
  2. Create an app password. Any name is fine. Google shows you a 16-letter code.
  3. Add these lines to the .env file as well, then save and close:
SMTP_USERNAME=your.address@gmail.com
SMTP_PASSWORD=the16lettercode
MAIL_TO=where.to.send.results@example.com

Use the 16-letter code here, not your regular Gmail password. MAIL_TO can be any email address. If you skip this step, just close TextEdit.

5

Choose days, times and courts

Double-click settings.command. A page opens in your browser with your settings.

  • Days: tick a day to turn it on, or untick it to turn it off. Monday, Wednesday and Friday start out on. The other days are there if you want them.
  • Time: choose a start time for each day that's on. Each day can have a different time. Courts are always booked for 2 hours.
  • Courts: click courts in the order you like them. Click one again to remove it. If you pick none, it books the first free court.
  • Only book these courts: tick this if you'd rather book nothing than get a different court.

Click Save settings and wait for the word Saved. Then close the page and the Terminal window.

6

Keep your Mac awake overnight

The app has to be running at midnight with a browser window open, so your Mac can't be asleep. Once a run starts, the app keeps the Mac awake by itself until it finishes. The wake time from step 2 helps too, but don't count on it alone.

  1. Open the Apple menu, then System Settings.
  2. On a laptop: click Battery, then Options, and turn on Prevent automatic sleeping on power adapter when the display is off.
  3. On a desktop Mac: click Energy and turn on Prevent automatic sleeping when the display is off.

The screen can still turn off. Then, on booking nights:

  • Leave the Mac plugged in, and leave the lid open. Closing the lid puts a laptop to sleep.
  • Stay logged in. Locking the screen is fine, but don't log out or shut down. If the Mac restarts for an update, log back in.
7

Run a test

Double-click dry-run.command. A browser window opens and works through the booking screens by itself. It takes about a minute and books nothing. Don't click in that window while it runs.

The Terminal window then shows one of these results:

ResultWhat it means
dry-runIt worked. It found a court and stopped before booking.
unavailableYour login works, but no court was free at that time. That's normal for popular times. It stopped before the price check, so try a less busy time in settings.command if you want to see a full dry-run.
limit-reachedYour login works, but you already have 2 hours booked that day, which is the site's daily limit.
errorSomething stopped it. See If something goes wrong.

You should also get a Mac notification, and an email if you did step 4. Missed notifications are in Notification Center: click the date and time at the top right of the screen. Check your junk folder for the first email.

8

Check the nightly job

Double-click status.command. It should say The nightly job is set up.

The morning after setup, double-click it again. It lists the last few nightly runs, which tells you whether your Mac stayed awake:

What it showsWhat it means
A line ending in 23:45 for last nightIt ran properly.
"No runs yet"It hasn't reached its first night yet.
A time much later than 23:45, or no line for last nightYour Mac was asleep and ran it when it woke up, which is too late. Go back to step 6.

The job runs every night, and that's normal. On nights with nothing to book, it exits straight away without any notification. Details of each run are in logs/booker.log in the app's folder.

A late run never books by mistake: the app only tries between 11 PM and 12:20 AM.

9

Turn on real booking

Do this once the test in step 7 worked and you've read Good to know.

  1. Open Terminal, type open -e ~/PB-Registration-HP/.env and press Return.
  2. Change the line to ALLOW_REAL_BOOKING=true.
  3. Save and close.

That's it. From now on, it books for real.

When it books

It starts at 11:45 PM to log in, then tries at midnight and keeps trying for about 10 minutes. It needs to run the night before a date opens:

To play onYour Mac must be awake on
MondayThursday night, 11 days before
WednesdaySaturday night, 11 days before
FridayMonday night, 11 days before

After each try you get a Mac notification, plus an email if you set that up, whether it worked or not.

ResultWhat it means
bookedYou have the court. It's on your Bookings page in Plan2Play. Plan2Play says it also emails a confirmation.
unavailableNo court was free at your exact time. It doesn't pick another time for you.
limit-reachedYou already hold 2 hours that day.
dry-runReal booking is still off (step 9).
errorSomething stopped it, so check your Bookings page.

Good to know

Bookings can cost you money. Canceling within 24 hours, or not showing up, is charged at the regular rate: $20/hr for Premier, $40/hr for Standard and $50/hr for nonmembers. On every booking, the app ticks the late, cancellation and no-show policy boxes for you. Watch for its messages, and cancel any court you don't want in time.

  • To cancel, go to Bookings in Plan2Play and click the red trash icon next to the court.
  • The site allows 2 hours of pickleball courts per day.
  • The app stops without booking if the plan shown isn't free, so it won't pay for a court. Check your first real result, as this depends on your membership.
  • Popular times may already be taken, so you may see unavailable often.
  • The site's security check blocks hidden browsers, so a browser window has to open at night. Don't close it.
  • The nightly run uses your Mac's clock, so keep the Mac set to Central time.

Changing or stopping it

To do thisDo this
Change days, times or courtsDouble-click settings.command and save. The next nightly run uses them.
Stop real booking but keep testingSet ALLOW_REAL_BOOKING=false in .env.
Pause or remove itDouble-click uninstall.command. To resume, run setup.command again. Courts you've already booked stay booked.
Remove it for goodDouble-click uninstall.command, then move the folder to the Trash.
Share it with a friendDouble-click share.command. It makes dist/PB-Registration-HP.zip without your passwords. It works for friends on a Mac or a Windows PC.

If something goes wrong

What you seeWhat to do
"can't be opened because Apple cannot verify it" or "not opened" when you double-click a .command fileRun setup from Terminal as in step 2. That clears the block for every file in the folder.
"Setup stopped: this folder is in Documents, Desktop, Downloads or iCloud Drive"Move the folder into your Home folder (step 1) and run setup again from there.
"Node.js isn't installed yet" or "node: command not found"Run setup again. If it still appears, install the LTS version from nodejs.org, then run setup again.
"Login did not go through"Check your login in .env, and that you can log in to Plan2Play yourself. If your password has a #, add the double quotes from step 3, and make sure they're straight quotes.
"Cloudflare stopped this browser with a security check"The site's security check turned it away. Try again later. If it keeps happening, the app can't be used on this Mac right now.
"Stopped: the plan offered isn't free"The app won't book a paid court. Book it yourself, or ask the club about your membership.
No result at all in the morningYour Mac was probably asleep, the lid was closed, or you were logged out. Check status.command as in step 8.
"Operation not permitted" in logs/booker.logThe folder is somewhere macOS protects. Move it into your Home folder and run setup again.
No email, but the notification appearsCheck your junk folder. Then check that SMTP_PASSWORD is the 16-letter app password.
"Could not send a notification" with "Application-specific password required"You used your regular Gmail password. Use the app password from step 4.
No Mac notificationOpen System Settings, then Notifications. Find Script Editor and turn on Allow notifications. Also check that Focus or Do Not Disturb is off.
