Pickleball Booker

Club Pickle & Padel, Highland Park. Books a court automatically at midnight, 10 days ahead. This page starts from the usual settings, not your saved ones, so set everything you want before saving.

1. Pick days and time

2. Pick courts (optional)

Click courts in the order you prefer them. Click again to remove one. If you pick none, the first free court is booked.

3. Save

Copy these settings, open config.json in the PB-Registration-HP folder on the PC that runs the booker, replace everything in it, and save. The next nightly run uses them.


    

      
    

  


  

    
4. Test it

    
In the PB-Registration-HP folder, run npm run dry-run:local. It logs in and finds the court without reserving it.
